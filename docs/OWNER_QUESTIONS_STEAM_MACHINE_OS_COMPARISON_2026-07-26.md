# Owner questions: Steam Machine OS comparison

Date: 2026-07-26

Status: eighteen unresolved choices; none authorizes execution or a Windows fallback

These choices must be frozen before the same-hardware campaign can run. Safe
defaults keep the comparison blocked, preserve SteamOS as primary, and retain
all adverse paired evidence.

## SMOC-001: exact received target and custody

Which delivered Steam Machine serial-free inventory, firmware, storage device,
peripherals and custody record defines the only eligible comparison target?

Safe default: select nothing until the preorder is physically received and a
path-free inventory digest is independently reviewed. No Windows workstation,
proxy, replacement model or vendor specification may substitute.

## SMOC-002: supported dual-boot route

Which Valve-supported partition, encryption, boot-selection, backup, update and
recovery flow is approved for the campaign?

Safe default: wait for an official supported route and qualify I-175 first. Do
not resize, reimage or repair the target from an unofficial guide.
