# Owner decisions from the RetroArch tranche

Last updated: 2026-07-23

No owner decision blocks the next software-only RetroArch work. Existing decisions define the Rust host, supervised local frontend, curated core/controller defaults, family-mode restrictions, rights policy, storage isolation, and branded launcher return.

The two outstanding product choices are resolved:

1. **2048 will be a permanent starter-catalog game.** It remains an uninstalled qualification candidate until its exact RetroArch/core artifacts, notices, controller behavior, and both target architectures pass qualification.
2. **Developer mode will offer session-gated access to the complete RetroArch menu.** The user must explicitly unlock it for the current diagnostic session, the launcher must visibly indicate the unlocked state, and access must relock when the session exits or the console reboots. Family mode retains the VCG-curated subset.

These decisions do not authorize downloading or distributing binaries, content, BIOS files, keys, artwork, or trademarks. Artifact selection and rights evidence remain engineering/review work before any distribution decision.
